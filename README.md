# Ang Paborito Kong Itlog

**Tagline:** Sarap ng Itlog, Sarap ng Pinoy eggs!

## Student Name
Tagros, Brent Louis N.

## Website category
Educational / food discovery website.

## Project description
An educational Filipino food discovery website featuring egg dishes, beginner-friendly recipes, an interactive quiz, and a client-side feedback form. Built as an individual Integrative Programming Technologies final project.

## Main features
- Five linked pages: Home, Dish Gallery, Recipe Corner, Itlog Quiz, and About.
- Dish search and category filtering with friendly empty states.
- Dish details modal and favorites stored in Local Storage.
- Five recipe cards with ingredient checklists that persist in Local Storage.
- Ten-question multiple-choice quiz with score, percentage, restart, and saved latest score.
- Client-side feedback form validation (does not send email or store feedback on a server).
- Responsive mobile navigation and layouts.

## Technologies used
HTML5, CSS3, Vanilla JavaScript, JSON, Local Storage, chatgpt.

## Local data and privacy
Favorites, recipe checklist progress, and the latest quiz score are stored in the browser's Local Storage. They stay on that browser/device unless the browser data is cleared. The feedback form is only a client-side demonstration and does not transmit or save submissions.
